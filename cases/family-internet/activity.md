# Журнал демонстрационного проекта

22 ноября 2026 года. Исходный управленческий запрос, аналитика, сценарные допущения и формулировки оформлены в текущей сессии Codex. Решения руководителя в повторах имеют отметку `simulation`. Учебный замер внесён как отдельный материал, интервью и операционные наблюдения не проводились.

| Что выполнено | Средства и результат |
|---|---|
| Чтение брифа и проверка таблицы | Извлечён текст 11 страниц PDF, проверена таблица показателей, подготовлены CSV-входы. |
| Сравнение рыночных механик | Проверены страницы поддержки МТС и T2, сохранены URL и краткие выдержки с границами применимости. |
| Количественные расчёты | `economics.py` рассчитывает 2 600 семей под совместный статистический порог и пять метрик в двух сценариях. |
| Контрольные точки | Чистый запуск 2,57 с, отдельный процесс восстановления 0,66 с, пересмотр 1,84 с. Проверены пять контрольных точек, 14 записей и 16 мест, связанных с новым материалом. Механика проверена на старте нового кейса про оплату роутера. |
| Модельная сверка | Два отдельных одноразовых сеанса Codex CLI получили срез исходных материалов и вывод команд из хоста. Первый сформулировал решение Q1; второй, получив сохранённый выбор и новый материал, отложил пилот. |
| Ошибки и проверка человеком | Вложенный Codex CLI из среды сборки не смог запустить собственную Windows-оболочку. Команды и вызов модели проверены по отдельности. В одном модельном ответе ограничение одним тарифом ошибочно отнесено к брифу; в итоговой стратегии оно обозначено как рамка, выбранная командой. |

| Затраты | Что удалось измерить |
|---|---|
| Офлайн-повтор | Платные API не вызываются. Время программ указано выше. |
| Первый модельный запуск | 21 224 входных токена, включая 15 232 кешированных, и 720 выходных. |
| Второй модельный запуск | 21 970 входных токенов, включая 15 232 кешированных, и 893 выходных. |
| Основной рабочий чат | Точный расход модели, полный хронометраж рабочего чата и стоимость подписки на один результат недоступны. |

Стоимость продукта и пилота рассчитана отдельно в [стратегии](strategy.md). Человеку принадлежит выбор финансирования, запуска и расширения. Воспроизводимый сценарий не требует действий человека между этапами, кроме запуска команд.

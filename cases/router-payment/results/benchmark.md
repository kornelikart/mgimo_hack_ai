# Сравнение на задаче про оплату роутера

Один парный прогон на одинаковом учебном брифе, таблице и новом замере. Обе ветки используют Codex с одинаковой настройкой модели. Каждый этап запускается в отдельной сессии. Сценарий обычного чата получает предыдущий текст в новом запросе. Агент загружает предыдущую стратегию и решение из файлов.

| Показатель | Агент с MCP | Обычный чат |
|---|---:|---:|
| Первый этап, секунд | 117.44 | 22.07 |
| Пересмотр, секунд | 91.91 | 20.08 |
| Найдено утверждений из рубрики | 4/4 | 4/4 |
| Найдено утверждений из рубрики без ссылки | 0 | 0 |
| Проверяемые контрольные точки | 5 | 0 |
| Перенос предыдущего ответа между сессиями | 0 | 1 |
| Правки текста при переносе | 0 | 0 |

Время от запуска процесса до записи ответа включает соединение с сервисом, вызовы MCP и проверки разрешений. Перенос в контрольном сценарии имитирован программно. Время человека на копирование не измерялось. Оценка ссылок проверяет наличие требуемых чисел и допустимой ссылки в ответе. Рубрика охватывает только четыре заранее выбранных утверждения.

## Наблюдения

В ответах агента найдено 4 из 4 утверждений, в ответах обычного чата — 4 из 4. Общее время двух этапов — 209.35 с у агента и 42.15 с у чата. Агент оставил проверяемые документы, сохранённое решение и карту затронутых выводов. Для оценки среднего качества или стоимости нужна серия кейсов.
